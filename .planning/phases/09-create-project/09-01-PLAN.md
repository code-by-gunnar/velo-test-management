# Plan 09-01: Create Project Modal

## Goal
Add a modal that lets users create new projects from the sidebar switcher dropdown. Handles form validation, slug auto-generation, free tier upsell, and post-creation navigation.

## Requirements Covered
- **PCR-01**: "+ New project" opens a modal with name and project key fields
- **PCR-02**: Project key auto-generated from name, editable before submission
- **PCR-03**: Free tier upsell message when limit reached
- **PCR-04**: Navigate to new project's test cases page after creation

## Success Criteria (from ROADMAP)
1. Clicking "+ New project" in switcher dropdown opens modal with name and project key fields
2. Project key auto-generates from name (e.g., "Mobile App" → "mobile-app") and is editable before submission
3. Modal calls `POST /api/workspaces/:id/projects` — on 201, navigates to new project's cases page
4. When API returns 403 with `code: "TIER_LIMIT_EXCEEDED"`, modal shows upsell message instead of form
5. Modal validates: name required, project key required + lowercase alphanumeric + hyphens only, handles 409 duplicate key inline

**Slug auto-generation:**
```typescript
function slugify(name: string): string {
  return name
    .toLowerCase()
    .replace(/\s+/g, "-")        // spaces → hyphens
    .replace(/[^a-z0-9-]/g, "")  // strip invalid chars
    .replace(/-+/g, "-")         // collapse multiple hyphens
    .replace(/^-|-$/g, "")       // trim leading/trailing hyphens
    .slice(0, 20)
}
```

**Name change handler:**
```typescript
function handleNameChange(value: string) {
  setName(value)
  if (!keyEdited) {
    setProjectKey(slugify(value))
  }
  setFieldError((prev) => ({ ...prev, name: undefined }))
}
```

**Key change handler:**
```typescript
function handleKeyChange(value: string) {
  const cleaned = value.toLowerCase().replace(/[^a-z0-9-]/g, "").slice(0, 20)
  setProjectKey(cleaned)
  setKeyEdited(true)
  setFieldError((prev) => ({ ...prev, project_key: undefined }))
}
```

**Submit handler:**
```typescript
async function handleSubmit(e: React.FormEvent) {
  e.preventDefault()
  setError("")
  setFieldError({})

  // Client-side validation
  const errors: { name?: string; project_key?: string } = {}
  if (!name.trim()) errors.name = "Project name is required"
  if (!projectKey.trim()) errors.project_key = "Project key is required"
  else if (!/^[a-z0-9-]+$/.test(projectKey)) errors.project_key = "Only lowercase letters, numbers, and hyphens"
  if (Object.keys(errors).length > 0) { setFieldError(errors); return }

  setLoading(true)
  try {
    const res = await fetch(`/api/backend/workspaces/${workspaceId}/projects`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ name: name.trim(), project_key: projectKey }),
    })

    if (res.status === 201) {
      const created = await res.json()
      // Update localStorage and navigate
      localStorage.setItem("velo:last-project-key", created.project_key)
      window.dispatchEvent(new StorageEvent("storage", { key: "velo:last-project-key" }))
      onClose()
      void router.push(`/app/${slug}/${created.project_key}/cases`)
      return
    }

    const data = await res.json()

    if (res.status === 403 && data.code === "TIER_LIMIT_EXCEEDED") {
      setTierLimited(true)
      return
    }

    if (res.status === 409 && data.field === "project_key") {
      setFieldError({ project_key: "This project key is already in use" })
      return
    }

    setError(data.error || "Something went wrong")
  } catch {
    setError("Network error. Please try again.")
  } finally {
    setLoading(false)
  }
}
```

## Edge Cases
1. **Double submit:** `disabled={loading}` prevents multiple clicks
2. **Network failure:** Caught with try/catch, shows generic error
3. **Empty key after name change:** If name is all special chars, key will be empty — client validation catches this
4. **Key with leading/trailing hyphens:** `slugify` trims them
5. **Modal opened then closed:** `useEffect` resets all state when `open` changes
6. **Navigation after create:** Modal closes before `router.push` to avoid stale modal state

## What This Plan Does NOT Cover
- Refreshing the ProjectSwitcher's project list after creation (the page navigation will cause a re-mount which re-fetches)
- Upgrade/pricing page (the upsell message is informational only — no link to upgrade yet)
