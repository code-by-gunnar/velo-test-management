   - refresh_token_enc TEXT
   - linear_org_id VARCHAR(255) NOT NULL

   - connected_by UUID FK users ON DELETE SET NULL
   - connected_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
   - UNIQUE(workspace_id) — one Linear connection per workspace
   - ENABLE ROW LEVEL SECURITY + FORCE + workspace_isolation policy

   **webhooks table:**
   - id UUID PK DEFAULT gen_random_uuid()
   - workspace_id UUID NOT NULL FK workspaces ON DELETE CASCADE
   - project_id UUID FK projects ON DELETE CASCADE (NULL = workspace-level default)
   - endpoint_url TEXT NOT NULL
   - secret VARCHAR(64) NOT NULL (HMAC-SHA256 signing secret)
   - events TEXT[] NOT NULL DEFAULT '{}' (array of event type strings)
   - active BOOLEAN NOT NULL DEFAULT true
   - created_by UUID FK users ON DELETE SET NULL
   - created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
   - updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
   - ENABLE ROW LEVEL SECURITY + FORCE + workspace_isolation policy

   **defects table alteration:**
