# Plan 12-01: Format Selection UI

## Goal
Users choose their test format (Traditional Steps or Given-When-Then) during project creation. The picker appears in both the onboarding flow and the Create Project modal. Project settings displays the chosen format as a read-only badge.

## Requirements Covered
- **GWT-07**: Onboarding flow includes a format picker step with two visual cards
- **GWT-08**: Create Project modal includes the same format picker
- **GWT-09**: Project settings General tab displays the chosen format as read-only

## Success Criteria (from ROADMAP)
1. Onboarding flow shows a format picker step with two visual cards after project name/key — "Traditional Steps" (Action/Expected columns preview) and "Given-When-Then" (keyword-prefixed steps preview)
2. Selected format is sent as `test_format` in the project creation API call
3. Create Project modal includes the same format picker below the name/key fields
4. Project settings General tab displays the chosen format as a read-only badge (not editable)

## Implementation

### Task 1: Create FormatPicker component

**New file:** `apps/web/src/components/projects/FormatPicker.tsx`

A shared component used by both onboarding and CreateProjectModal.

```tsx
import { clsx } from "clsx"

type TestFormat = "steps" | "gwt"

interface FormatPickerProps {
  value: TestFormat
  onChange: (format: TestFormat) => void
}

export function FormatPicker({ value, onChange }: FormatPickerProps) {
  return (
    <div className="grid grid-cols-2 gap-3">
      <FormatCard
        selected={value === "steps"}
        onClick={() => onChange("steps")}
        title="Traditional Steps"
        description="Action and Expected Result columns"
        preview={<StepsPreview />}
      />
      <FormatCard
        selected={value === "gwt"}
        onClick={() => onChange("gwt")}
        title="Given-When-Then"
        description="BDD keyword-prefixed steps"
        preview={<GwtPreview />}
      />
    </div>
  )
}
```

**FormatCard** (internal to the same file):
- A clickable card with `role="radio"` for accessibility
- Selected state: `border-primary bg-primary-selected` with a small checkmark or ring
- Unselected state: `border-gray-200 bg-white hover:border-gray-300`
- Content: title (font-medium text-sm), description (text-xs text-gray-500), mini preview

**StepsPreview** (internal):
A small visual mock showing two mini rows with "Action" and "Expected" column headers — just gray placeholder bars, not real text. Uses `bg-gray-200 rounded` bars to represent content. Compact, ~40px tall.

```tsx

```

**GwtPreview** (internal):
A small visual mock showing keyword pills + text bars:

```tsx
function GwtPreview() {
  return (
    <div className="mt-2 space-y-1">
      {(["Given", "When", "Then"] as const).map((kw) => (
        <div key={kw} className="flex items-center gap-1.5">

```

**Design notes:**
- Card padding: `p-3`
- Card radius: `rounded-md` (8px per design system)
- Selected border: `border-primary` (2px) with `bg-primary-selected`
- Transition: `transition-colors` for smooth hover/select
- Cursor: `cursor-pointer`
- Focus: `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2` for keyboard users

## Backwards Compatibility
- `test_format` defaults to `"steps"` everywhere — existing projects display "Traditional Steps"
- No API changes needed — backend already supports the field
- Onboarding and modal still work if FormatPicker is omitted (would default to 'steps')

## Edge Cases
1. **Existing projects without test_format value:** Impossible — column has NOT NULL DEFAULT 'steps'. But the settings page defensively defaults to 'steps' via `?? "steps"`.
2. **Modal reset on close:** `testFormat` resets to `defaultFormat` (the smart default) in `handleClose`, so reopening the modal starts with the workspace's most recent format.
3. **Keyboard accessibility:** FormatCard uses `role="radio"` and responds to Enter/Space. `tabIndex={0}` on each card.
4. **Responsive:** The 2-column grid (`grid-cols-2`) works down to ~320px. Cards are compact enough for the modal's `max-w-md`.
