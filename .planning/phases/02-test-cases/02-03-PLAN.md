**StepRow.tsx** — single Action | Expected row:
```typescript
interface StepRowProps {
  index: number
  action: string
  expected_result: string
  isLast: boolean
  onChange: (index: number, field: "action" | "expected_result", value: string) => void
  onAddAfter: (index: number) => void
  onDelete: (index: number) => void
  actionRef: React.RefObject<HTMLTextAreaElement>
  expectedRef: React.RefObject<HTMLTextAreaElement>
}
```

Key implementation details for StepRow:
- Use `<textarea>` (NOT `<input>`) for both Action and Expected fields — multi-line step content
- `rows={1}` + `className="resize-none overflow-hidden"` — auto-resize height via `onInput` event: `e.target.style.height = 'auto'; e.target.style.height = e.target.scrollHeight + 'px'`
- `onKeyDown` on Action:
  1. `if (key === "Tab" && !shiftKey) { e.preventDefault(); expectedRef.current?.focus() }`
  2. `if (key === "Backspace" && value === "" && index > 0) { e.preventDefault(); onDelete(index) }`
- `onKeyDown` on Expected:
  1. `if (key === "Tab" && !shiftKey) { e.preventDefault(); onAddAfter(index) }`
  2. `if (key === "Enter" && !shiftKey) { e.preventDefault(); onAddAfter(index) }`
  3. `if (key === "Tab" && shiftKey) { e.preventDefault(); actionRef.current?.focus() }`
- e.preventDefault() MUST be first line in each keydown handler — not after any async call

**StepEditor.tsx**:
```typescript
interface StepEditorProps {
  steps: Array<{ action: string; expected_result: string }>
  onChange: (steps: Array<{ action: string; expected_result: string }>) => void
}
```
- Maintains refs array: `const stepRefs = useRef<Array<{ action: React.RefObject<HTMLTextAreaElement>; expected: React.RefObject<HTMLTextAreaElement> }>>([])` — sync length with steps.length
- `onAddAfter(index)`: insert new `{ action: "", expected_result: "" }` at index+1 in steps array, then `setTimeout(() => stepRefs.current[index+1]?.action.current?.focus(), 0)`
- `onDelete(index)`: remove step at index, then `setTimeout(() => stepRefs.current[index-1]?.expected.current?.focus(), 0)`
- Two-column grid layout: `grid grid-cols-2 gap-2` per row; column headers "Action" / "Expected Result" in a header row
