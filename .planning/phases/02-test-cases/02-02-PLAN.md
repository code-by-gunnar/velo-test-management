**GET /suites** — recursive CTE:
```sql
WITH RECURSIVE suite_tree AS (
  SELECT id, name, parent_id, position, 0 AS depth
  FROM   suites
  WHERE  project_id = $projectId
    AND  parent_id IS NULL
    AND  workspace_id = current_setting('app.workspace_id', true)::uuid

  UNION ALL

  SELECT s.id, s.name, s.parent_id, s.position, st.depth + 1
  FROM   suites s
  JOIN   suite_tree st ON s.parent_id = st.id
  WHERE  s.workspace_id = current_setting('app.workspace_id', true)::uuid
)
SELECT * FROM suite_tree ORDER BY depth, position
```

**POST /suites** — body: `{ name: string, parent_id?: string }`. Compute initial position as MAX(position)+1000 among siblings (same parent_id, same project). If no siblings, position = 1000. INSERT and return the new row.

**PATCH /suites/:suiteId** — body: `{ name: string }`. UPDATE name only.

**PATCH /suites/:suiteId/position** — body: `{ position: number }`. Single UPDATE on position column.

**DELETE /suites/:suiteId** — DELETE the row. test_cases.suite_id FK is ON DELETE SET NULL so cases are unparented, not deleted.

**GET /cases**:
```sql
SELECT tc.id, tc.suite_id, tc.title, tc.preconditions, tc.priority, tc.position,
       COUNT(tcs.id)::int AS step_count
FROM   test_cases tc
LEFT JOIN test_case_steps tcs ON tcs.test_case_id = tc.id
WHERE  tc.project_id = $projectId
  AND  tc.deleted_at IS NULL
  -- Optional: AND tc.suite_id = $suiteId (when query param provided)
GROUP BY tc.id
ORDER BY tc.position
LIMIT  500
```

**POST /cases** — body: `{ suite_id?: string, title: string, preconditions?: string, priority: string, steps: Array<{ action: string, expected_result?: string }> }`:
```typescript
// In withWorkspace transaction:
// 1. Check tier limit: SELECT COUNT(*) FROM test_cases WHERE project_id=... AND deleted_at IS NULL
// 2. INSERT test_cases row, get new id
// 3. INSERT INTO test_case_steps (id, test_case_id, step_order, action, expected_result)
//    VALUES (uuidv7(), $caseId, $index*1000+1000, $action, $expected)  for each step
// All in same tx — withWorkspace transaction
```

**GET /cases/:caseId**:
```sql
SELECT tc.*, array_agg(
  json_build_object('id', tcs.id, 'step_order', tcs.step_order, 'action', tcs.action, 'expected_result', tcs.expected_result)
  ORDER BY tcs.step_order
) AS steps
FROM test_cases tc
LEFT JOIN test_case_steps tcs ON tcs.test_case_id = tc.id
WHERE tc.id = $caseId AND tc.deleted_at IS NULL
GROUP BY tc.id
```

**PUT /cases/:caseId** — same body shape as POST. In transaction: UPDATE test_case fields, DELETE FROM test_case_steps WHERE test_case_id = $caseId, INSERT new steps.

**DELETE /cases/:caseId**: `UPDATE test_cases SET deleted_at = NOW() WHERE id = $caseId`
