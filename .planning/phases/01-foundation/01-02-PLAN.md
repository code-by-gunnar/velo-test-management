**File 1: `apps/api/src/queues/lifecycle.worker.ts`**

Follow the exact pattern from `email.worker.ts`. Create:

```typescript
import { Worker } from "bullmq"
import { getBullMQWorkerConnectionOptions } from "../lib/valkey.js"
import { sql } from "../db/client.js"
import { logAuditEvent } from "../lib/audit-log.js"
import type { LifecycleJobData } from "./lifecycle.queue.js"
```

Create `lifecycleWorker` as `new Worker<LifecycleJobData>("lifecycle", async (job) => { ... })` with:
- `connection: getBullMQWorkerConnectionOptions()`
- `concurrency: 1` (lifecycle jobs must not run concurrently — atomic status claim handles races but concurrency 1 is safer)

The worker handler switches on `job.data.type`:

- `'workspace-delete'`: Log `[lifecycle-worker] workspace-delete job ${job.id} — will be implemented in Phase 2` and return. This is a skeleton — Phase 2 adds the actual deletion logic.

- `'user-erasure'`: Log `[lifecycle-worker] user-erasure job ${job.id} — will be implemented in Phase 2` and return. Skeleton for Phase 2.

- `'sweep-expired'`: Implement the actual sweep logic NOW (this is INF-03):
  1. Query expired workspace deletions: `SELECT id FROM workspaces WHERE deletion_status = 'pending_deletion' AND deletion_scheduled_at < NOW()`
  2. Query expired user erasures: `SELECT id, user_id, workspace_id FROM user_erasure_requests WHERE status = 'pending' AND scheduled_at < NOW()`
  3. For each expired workspace: re-enqueue a `workspace-delete` job with `jobId: ws-delete:${workspaceId}` (use `{ delay: 0 }` for immediate processing)
  4. For each expired user erasure: re-enqueue a `user-erasure` job with `jobId: user-erase:${userId}` (use `{ delay: 0 }`)
  5. Log count of re-enqueued jobs: `[lifecycle-worker] sweep found ${wsCount} expired workspaces, ${userCount} expired erasures`

Import `lifecycleQueue` from `./lifecycle.queue.js` for the re-enqueue step.

Add event handlers matching email.worker.ts pattern:
```typescript

})
lifecycleWorker.on("failed", (job, err) => {
  console.error(`[lifecycle-worker] Job ${job?.id} failed:`, err.message)
})
```
