Create `apps/web/src/components/settings/TeamPanel.tsx` with the following sections:

**Props:** `{ workspaceId: string, userRole: string | null }`

**State:** members list, pending invites list, invite form (email + role), loading states, error messages.

**Layout (top to bottom):**

1. **Invite form** (only visible if userRole === "admin"):
   - Email input (text) + Role select (admin/editor/viewer dropdown) + "Send Invite" button
   - On submit: POST `/api/backend/workspaces/${workspaceId}/invitations` with `{ email, role }`
   - Show success toast or error message (TIER_LIMIT_EXCEEDED shows upgrade prompt)
   - After success, refresh pending invites list

2. **Pending invitations section** (only visible if admin and pending invites exist):
   - Table/list showing email, role, expires_at for each pending invite
   - "Resend" button per row (re-POSTs invitation for same email)

3. **Members list:**
   - Table with columns: Email, Role, Joined, Actions
   - Each row shows member email, role badge, joined date
   - If admin: role column is a `<select>` dropdown (admin/editor/viewer) — onChange fires PATCH role change
   - If admin: "Deactivate" button per row (except for the current user's own row)
   - Deactivate shows confirmation prompt before firing PATCH deactivate
   - On role change or deactivate success, refresh members list

**Data fetching:**
- On mount: fetch GET `/api/backend/workspaces/${workspaceId}/members` for member list
- On mount (if admin): fetch GET `/api/backend/workspaces/${workspaceId}/invitations` for pending invites
- Use `useCallback` pattern for fetch functions (same as other panels)

**Styling:**
- Follow existing panel patterns (ApiKeysPanel, IntegrationsPanel) for card layout, spacing, typography
- Use Tailwind classes consistent with design system (border-gray-200, text-gray-900, bg-cobalt for primary actions)
- Role badges: admin=cobalt, editor=blue, viewer=gray (use StatusBadge pattern or inline)

**ESLint compliance:**
- Do NOT use `setState` inside `useEffect` body directly — use `useCallback` wrapper pattern
