Update the `GET /api/me/avatar-url` endpoint in `apps/api/src/routes/profile.ts` to detect external URLs and return them directly:

Replace the current avatar-url handler with:

```typescript
fastify.get("/api/me/avatar-url", async (request, reply) => {
  const [user] = await sql`
    SELECT avatar_url
    FROM users
    WHERE id = ${request.userId}::uuid
  `

  if (!user || !(user as { avatar_url: string | null }).avatar_url) {
    return reply.send({ url: null })
  }

  const avatarKey = (user as { avatar_url: string }).avatar_url

  // External URLs (OAuth profile pictures) are returned directly
  if (avatarKey.startsWith("https://")) {
    return reply.send({ url: avatarKey })
  }

  // R2 keys are presigned for 1-hour access
  const url = await getR2PresignedUrl(avatarKey)
  return reply.send({ url })
})
```

This is backward-compatible: existing R2 keys (e.g., `avatars/uuid/12345.jpg`) still get presigned. New OAuth-seeded URLs (e.g., `https://lh3.googleusercontent.com/...`) are returned as-is.
